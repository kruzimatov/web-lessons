Lesson 1 · Week 1What is HTML? Your first web page

LessonPracticeHomework
When I'm stuck
  1. Read my code slowly, line by line.
  2. Press Check my code and read what it says.
  3. Check that every tag that opens also closes.
  4. Look it up in My tags.
  5. Compare with the example in the lesson.
  6. Try Hint 1, then Hint 2.
  7. Still stuck? Ask your teacher.

Task 1 · Easy

Make a big title with your name, and a paragraph with your age.

Hint 1

Which tag makes the biggest title?

Hint 2

<h1>Your name</h1>, then <p>I am ... years old.</p>

Task 2 · Medium

Stairs: write all 6 headings, from h1 down to h6, with your own words.

Hint 1

Start with <h1> and go down one number each line.

Hint 2

The last one is <h6>.

Task 3 · Find the bug

There are 3 mistakes. Fix them.

Hint 1

Look at every closing tag. Does it have a /? Does it end with >?

Hint 2

Line 1 needs </h1>, line 2 needs </p>, line 3 opens h2 but closes h3.

Task 4 · Medium

Build a full page from zero: the skeleton, a title "About Me", an h1 and a p.

Hint 1

Start with <!DOCTYPE html>, then <html>.

Hint 2

Inside html: <head> with <title>, then <body> with your h1 and p.

Task 5 · Mini project

"My Favorite Animal" page: one h1, two h2 parts ("What it eats", "Where it lives"), a p under each h2, and a comment above each part.

Hint 1

You need 1 h1, 2 h2, 2 p and 3 comments.

Hint 2

A comment looks like <!-- Food -->. Put one above each part.
