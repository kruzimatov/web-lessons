Lesson 1 · Week 1What is HTML? Your first web page

LessonPracticeHomework

Write your code in the boxes. It saves by itself. When you finish, press Copy my homework and send it to your teacher on Telegram. Finish your homework on the same device you started on.

When I'm stuck
  1. Read my code slowly, line by line.
  2. Press Check my code and read what it says.
  3. Check that every tag that opens also closes.
  4. Look it up in My tags.
  5. Compare with the example in the lesson.
  6. Try Hint 1, then Hint 2.
  7. Still stuck? Ask your teacher.

Task 1

"My Family": an h1, then a p about 3 people in your family.

Task 2

Upside-down stairs: write the headings from h6 up to h1.

Task 3 · Your idea

Your idea! Build any page you like. Use at least 3 things from today, for example <h1>Title</h1>, <p>Text</p>, <!-- note -->, <!DOCTYPE html>. No idea? Try: a superhero I made up, my football team, space and planets.
