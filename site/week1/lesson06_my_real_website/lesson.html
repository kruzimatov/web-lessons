Part 1: Your website folder

Until now we wrote code in the browser. Real websites are files in a folder. We use VS Code, a free program for writing code.

  1. Ask a parent to install VS Code: code.visualstudio.com
  2. On the Desktop, make a new folder: my-website
  3. Open VS Code. Click File, then Open Folder, choose my-website
  4. Click the New File icon and name it index.html

Sayt bu papka. Har bir sahifa alohida .html fayl.

index.html is special: it is always the home page of a website.

Practise here first: write the name of your website in an <h1> and a welcome <p>.

What is the name of the home page file?

Part 2: The magic shortcut

In index.html, type ! and press Tab. VS Code writes the whole skeleton for you!

New lineWhat it means
lang="en"This page is in English
<meta charset="UTF-8">Show all letters correctly: ö, ğ, ü, emoji
<meta name="viewport" ...>Look good on phones and iPads
  1. Change Document to your page title
  2. Write your <h1> and <p> in the body
  3. Save: Cmd + S (Windows: Ctrl + S)
  4. Open the my-website folder and double-click index.html. It opens in Chrome!
  5. Change something, save, then press Refresh in Chrome

Part 3: Two pages, joined by links

Make a second file: hobbies.html. To link to YOUR OWN page, write only the file name. No https://.

Put the same menu on every page. Then you can always go back home.

Write the menu for a site with 3 pages: Home, Hobbies and Pets (pets.html).

How do you link to your page pets.html?

Watch out!

  • File saved as index.txt. The name must end with .html
  • Forgot to save before refreshing Chrome
  • Spaces or capitals in file names. Use my-pets.html, not My Pets.html
  • The link name and the file name are different: hobby.html vs hobbies.html
