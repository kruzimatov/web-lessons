When I'm stuck
  1. Read my code slowly, line by line.
  2. Press Check my code and read what it says.
  3. Check that every tag that opens also closes.
  4. Look it up in My tags.
  5. Compare with the example in the lesson.
  6. Try Hint 1, then Hint 2.
  7. Still stuck? Ask your teacher.

Task 1 · Easy

Write the code for your index.html: skeleton, title "Home", an h1 and a p. Then copy it into VS Code, save and open it in Chrome.

Hint 1

Type ! and press Tab in VS Code.

Hint 2

Change Document to Home.

Task 2 · Medium

Write hobbies.html: skeleton, title "Hobbies", an h1 and a list of 3 hobbies. Make it in VS Code too.

Hint 1

Same skeleton, new title.

Hint 2

A list is <ul> with 3 <li>.

Task 3 · Find the bug

These links do not work. There are 3 mistakes. Fix them. (The files are index.html, hobbies.html, pets.html.)

Hint 1

Your own pages: no https, and the name must be exact.

Hint 2

index.html, hobbies.html, pets.html.

Task 4 · Medium

Add the menu (Home | Hobbies) at the top of BOTH pages in VS Code. Click the links in Chrome: can you go back and forth?

Hint 1

The menu is 2 links with | between them.

Hint 2

Put it as the first line in the body.
