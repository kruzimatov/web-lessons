Part 1: Two kinds of lists

Lists are everywhere: shopping lists, game rules, top-5 lists. HTML has two kinds.

TagMeansUse it when
<ul>Unordered list (dots)Order does not matter: a shopping list
<ol>Ordered list (numbers)Order matters: steps, a top 5
<li>List itemEvery item, in both lists

ul: tartib muhim emas. ol: tartib muhim, raqamlar bilan.

Write your own shopping list. Add 2 more items.

Change ol to ul in both places. What changes? Change it back.

You write the steps to make tea. Which list?

Part 2: Lists inside lists

An <li> can hold a whole new list. Like a box with smaller boxes inside.

Ichki ro'yxat li ichiga yoziladi, </li> dan oldin.

Add a small list under Drinks: Water and Juice.

Use spaces at the start of lines (Tab key) so you can see which list is inside which. The browser ignores them, but your eyes love them.

Where does the small list go?

Part 3: Change the numbers

<ol> can start from another number, or use letters instead of numbers.

AttributeWhat it does
start="5"Start counting from 5
type="A"A, B, C
type="a"a, b, c
type="I"I, II, III (Roman numbers)
reversedCount down: 3, 2, 1

Make a countdown: 3, 2, 1, then "Go!". Try type="I" too.

Which list shows A, B, C?

Watch out!

  • Text outside <li>: every item needs its own <li>
  • Closing the small list in the wrong place. It must end before </li>
  • Using <ul> for steps. If order matters, use <ol>
  • Writing <ol start=5> with no quotes. Use start="5"
