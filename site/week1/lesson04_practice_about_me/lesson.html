Part 3: Check your page

Before you finish, check these 4 things:

  1. Every tag that opens also closes (except <br> and <hr>)
  2. Only ONE <h1> on the page
  3. Everything you want to see is inside <body>
  4. Every list item is inside <li>

This page has 4 mistakes. Find them all!

How many <h1> should a page have?

Watch out!

  • Two <h1> on one page. Use <h2> for the parts
  • Forgetting </body> at the end
  • Closing tags in the wrong order: <p><strong>Hi</p></strong>
  • Items in a list without <li>
