When I'm stuck
  1. Read my code slowly, line by line.
  2. Press Check my answer and look at the goals without a tick.
  3. Press Check my code and read what it says.
  4. Check that every tag that opens also closes.
  5. Look it up in My tags.
  6. Compare with the example in the lesson.
  7. Try Hint 1, then Hint 2.
  8. Still stuck? Ask your teacher.

Task 1 · Easy

Make one link to Wikipedia with the text "Learn everything", opening in a new tab.

  • A link to Wikipedia
  • The address starts with https://
  • The link says "Learn everything"
  • Opens in a new tab: target="_blank"
Hint 1

A link is <a href="...">text</a>.

Hint 2

Add target="_blank" inside the opening tag.

Task 2 · Medium

Write a sentence with a link in the middle: "I like space pictures from NASA." Only "NASA" is the link.

  • The sentence is in a p
  • Only "NASA" is the link
  • It goes to nasa.gov
Hint 1

Only one word is inside the <a>.

Hint 2

from <a href="https://www.nasa.gov" target="_blank">NASA</a>.

Task 3 · Find the bug

There are 3 mistakes. Fix them.

  • The Wikipedia link closes with </a>
  • Quotes and https:// in the Wikipedia address
  • _blank starts with _
  • Both links open in a new tab
Hint 1

Check the quotes, the https://, the closing tags, and _blank.

Hint 2

href needs quotes and https://. Wikipedia needs </a>. blank needs _.

Task 4 · Medium

A menu: an h2 "My links" and a dots list of 3 links (Wikipedia, NASA, YouTube), each with a title.

  • A dots list
  • A link in every item
  • Wikipedia, NASA and YouTube
  • Every link has a title
Hint 1

Each link goes inside an <li>.

Hint 2

Add title="..." inside each <a>.

Task 5 · Mini project

"Learn about animals" page: an h1, a p, and a numbers list of 3 animals. Each animal name is a link to its Wikipedia page, for example https://en.wikipedia.org/wiki/Lion.

  • An h1
  • A p
  • A numbers list of 3 animals
  • Each animal links to its Wikipedia page
Hint 1

Numbers list with 3 <li>.

Hint 2

Each animal: <a href="https://en.wikipedia.org/wiki/Lion" target="_blank">Lion</a>.
