LessonPracticeHomework

Write your code in the boxes. It saves by itself. When you finish, press Copy my homework and send it to your teacher on Telegram. Finished homework wins 10 diamonds for the Game Zone. Log in, and your homework saves on every device.

When I'm stuck
  1. Read my code slowly, line by line.
  2. Press Check my code and read what it says.
  3. Check that every tag that opens also closes.
  4. Look it up in My tags.
  5. Compare with the example in the lesson.
  6. Try Hint 1, then Hint 2.
  7. Still stuck? Ask your teacher.

Task 1

Make 3 links to websites you like (ask a parent which ones are OK). Each opens in a new tab.

Task 2

Write 2 sentences about your hobby. Put one link inside each sentence.

Task 3 · Your idea

Your idea! Build any page you like. Use at least 3 things from today, for example <a href="https://www.nasa.gov">NASA</a>, target="_blank", title="Space". No idea? Try: cars, a magic world, my birthday party.
