Part 1: Your first form

A form lets people send you information: sign up, write a message, answer a quiz.

TagWhat it does
<form>Holds the whole form
<label>The words next to a box
<input>A box to type in. No closing tag
<button>The button that sends the form

for="name" on the label and id="name" on the input join them. Click the label: the box gets ready for typing!

label ning for= qiymati input ning id= qiymati bilan bir xil bo'lsin.

Type your name and press Send. Then click the label "Your name".

Watch out!

  • Writing </input>. <input> has no closing tag
  • The label for and the input id are different
  • Using type="text" for a password: everyone can read it
  • Forgetting the <button>: there is no way to send
