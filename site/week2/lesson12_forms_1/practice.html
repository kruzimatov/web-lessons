LessonPracticeHomework
When I'm stuck
  1. Read my code slowly, line by line.
  2. Press Check my answer and look at the goals without a tick.
  3. Press Check my code and read what it says.
  4. Check that every tag that opens also closes.
  5. Look it up in My tags.
  6. Compare with the example in the lesson.
  7. Try Hint 1, then Hint 2.
  8. Still stuck? Ask your teacher.

Task 1 · Easy

A form with a label "Favorite food", a text box and a button "Send".

  • A form
  • A label "Favorite food"
  • A text box
  • Every label's for is the same as its box's id
  • A Send button
Hint 1

form, label, input, button.

Hint 2

label for="food" and input id="food".

Task 2 · Medium

A login form: Email and Password boxes, each with a label, and a "Log in" button.

  • An email box
  • A password box
  • A label for each box
  • Every label's for is the same as its box's id
  • A Log in button
Hint 1

Email box: type="email". Password box: type="password".

Hint 2

Each box has its own label with matching for and id.

Task 3 · Find the bug

There are 3 mistakes. Fix them.

  • The name box has id="name"
  • No </input>: input never closes
  • The password box hides the letters
Hint 1

Check the ids, the closing tags, the password type.

Hint 2

id="nam" should be name. Delete </input>. Password needs type="password".

Task 4 · Medium

  • A label "How old are you?"
  • A number box
  • From 1 to 100
  • Placeholder "Your age"
  • required
Hint 1

type="number" with min and max.

Hint 2

Add placeholder="Your age" and required.

Task 5 · Mini project

"Join my club" sign-up form: name (required), email, password, birthday (date), and a "Join" button. Each box has a label and a placeholder where it fits.

  • Name is required
  • An email box
  • A password box
  • A birthday date box
  • A label for every box
  • Every label's for is the same as its box's id
  • A placeholder
  • A Join button
Hint 1

4 boxes: text, email, password, date.

Hint 2

Put each label and box in its own <p>.
