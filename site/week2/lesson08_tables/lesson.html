Part 1: Rows and cells

A table shows information in rows and columns, like a school timetable.

TagMeans
<table>The whole table
<tr>Table row: one line across
<td>Table data: one cell (box)

tr bu qator. td bu bitta katak. Avval qator, keyin uning kataklari.

Add a third row: Wednesday, School, Swimming.

Which tag makes a new row?

Part 2: Header cells

The first row usually has the titles of the columns. Use <th> instead of <td>: it is bold and centered.

TagMeans
<th>Table header: a title cell, bold
<thead>The top part, with the title row
<tbody>The body, with all other rows

Make a scoreboard: columns Player and Goals, and 3 players.

Which tag makes a bold title cell?

Part 3: Big cells

A cell can be wider than one column: colspan="2". Or taller than one row: rowspan="2".

colspan katakni eniga cho'zadi, rowspan bo'yiga.

Add a Sunday row where one cell says "Family day" across 2 columns.

One cell 3 columns wide. What do you write?

Watch out!

  • Writing <td> without a <tr> around it
  • Rows with different numbers of cells: the table looks broken
  • Forgetting border="1": the table has no lines and looks like plain text
  • Using <td> for the title row instead of <th>
