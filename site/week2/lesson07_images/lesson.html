Part 1: The img tag

Pictures make a page fun. The tag is <img>. It has no closing tag: the picture is the content.

PartMeaning
<img>Image. No closing tag
src="..."Source: where the picture is
alt="..."Words that describe the picture, for people who cannot see it

src bu rasm manzili. alt bu rasm haqida so'z: rasm ochilmasa, shu yoziladi.

Change the src number 237 to 1025. What animal is it now? Change the alt too.

Now break it on purpose: delete one letter from the src. What do you see instead of the picture? That is the alt!

What does alt do?

Part 2: Picture size

width makes a picture wider or smaller. The number is in pixels, tiny dots on the screen.

Use only width. The browser changes the height for you, so the picture is not squeezed.

Make the 3 pictures the same size: all width="200".

Which one changes the size of a picture?

Part 3: Your own pictures, and pictures you can click

For your real website, put pictures in an images folder inside my-website. Then the src is the folder name, a /, and the file name.

  1. In VS Code, make a new folder in my-website: images
  2. Ask a parent to help you save a photo into it, for example cat.jpg
  3. Write <img src="images/cat.jpg" alt="...">

Put an <img> inside an <a> and the picture becomes a link!

Make the bird picture a link to https://en.wikipedia.org/wiki/Bird.

Your picture dog.png is in the images folder. What is the src?

Watch out!

  • Writing </img>. <img> has no closing tag
  • No alt. Every picture needs words that describe it
  • Wrong file name: Cat.JPG and cat.jpg are different names
  • Setting width AND a wrong height. The picture gets squeezed
