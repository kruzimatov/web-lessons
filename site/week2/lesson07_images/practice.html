When I'm stuck
  1. Read my code slowly, line by line.
  2. Press Check my code and read what it says.
  3. Check that every tag that opens also closes.
  4. Look it up in My tags.
  5. Compare with the example in the lesson.
  6. Try Hint 1, then Hint 2.
  7. Still stuck? Ask your teacher.

Task 1 · Easy

Show the puppy picture with a good alt. Puppy: https://picsum.photos/id/237/400/300

Hint 1

<img src="..." alt="...">

Hint 2

alt: what is in the picture? A black puppy.

Task 2 · Medium

An h2 "Wild animals" and 3 pictures (lioness 1074, leopard 219, walruses 1084), all width="200". Change only the number in the address.

Hint 1

Change only the number: 1074, 219, 1084.

Hint 2

Each one: width="200".

Task 3 · Find the bug

There are 3 mistakes. Fix them.

Hint 1

Look at the spelling of src. Does img close? Does every picture have alt?

Hint 2

scr should be src. Delete </img>. Add alt to the pug.

Task 4 · Medium

Make the leopard picture a link to https://en.wikipedia.org/wiki/Leopard, opening in a new tab.

Hint 1

Put the <img> inside an <a>.

Hint 2

<a href="..." target="_blank"><img ...></a>

Task 5 · Mini project

"Animal cards": for 3 animals, an h2 with the name, a picture (width="200") and a p with one fact. Make each picture a link to its Wikipedia page.

Hint 1

For each animal: h2, a with img inside, p.

Hint 2

Copy one animal, then change the words 2 times.
