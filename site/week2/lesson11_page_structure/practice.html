LessonPracticeHomework
When I'm stuck
  1. Read my code slowly, line by line.
  2. Press Check my code and read what it says.
  3. Check that every tag that opens also closes.
  4. Look it up in My tags.
  5. Compare with the example in the lesson.
  6. Try Hint 1, then Hint 2.
  7. Still stuck? Ask your teacher.

Task 1 · Easy

A <div> painted lightgreen with an h2 and a p inside.

Hint 1

<div style="background-color: lightgreen">

Hint 2

Put the h2 and p inside, then </div>.

Task 2 · Medium

Write a sentence and paint 2 words yellow with <span>.

Hint 1

<span style="background-color: yellow">

Hint 2

Only the 2 words go inside the span.

Task 3 · Find the bug

There are 3 mistakes. Fix them.

Hint 1

Does header close? How many main? Check the spelling.

Hint 2

Add </header>. One main only. </foter> should be </footer>.

Task 4 · Medium

Put the parts in the right boxes: header (h1), nav (2 links), main with 2 sections, footer (copyright).

Hint 1

Top: header. Menu: nav. Content: main. Bottom: footer.

Hint 2

Each h2 + p goes inside its own <section>.

Task 5 · Mini project

A full page "My school": header, nav, main with 3 sections (teachers, subjects as a list, timetable as a table), and footer. Paint the header with a color.

Hint 1

Start with the 4 boxes, then fill main.

Hint 2

Section 2 has a ul, section 3 has a table.
