When I'm stuck
  1. Read my code slowly, line by line.
  2. Press Check my answer and look at the goals without a tick.
  3. Press Check my code and read what it says.
  4. Check that every tag that opens also closes.
  5. Look it up in My tags.
  6. Compare with the example in the lesson.
  7. Try Hint 1, then Hint 2.
  8. Still stuck? Ask your teacher.

Task 1 · Easy

A <div> painted lightgreen with an h2 and a p inside.

  • A div painted lightgreen
  • An h2 inside
  • A p inside
Hint 1

<div style="background-color: lightgreen">

Hint 2

Put the h2 and p inside, then </div>.

Task 2 · Medium

Write a sentence and paint 2 words yellow with <span>.

  • A sentence in a p
  • A span painted yellow
  • 2 words in the span
Hint 1

<span style="background-color: yellow">

Hint 2

Only the 2 words go inside the span.

Task 3 · Find the bug

There are 3 mistakes. Fix them.

  • The header closes: </header>
  • Only one main
  • </footer> is spelled right
Hint 1

Does header close? How many main? Check the spelling.

Hint 2

Add </header>. One main only. </foter> should be </footer>.

Task 4 · Medium

Put the parts in the right boxes: header (h1), nav (2 links), main with 2 sections, footer (copyright).

  • header with the h1
  • nav with the 2 links
  • main with 2 section
  • footer with the copyright
Hint 1

Top: header. Menu: nav. Content: main. Bottom: footer.

Hint 2

Each h2 + p goes inside its own <section>.

  • main with 3 section
