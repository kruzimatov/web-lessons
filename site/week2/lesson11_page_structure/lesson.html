Part 1: div and span

<div> is a plain box for a group of things. <span> is a box for a few words inside a line.

Boxes are invisible! To see them, here is a sneak peek of CSS (next month): style="background-color: ..." paints a box.

TagWhat it isStarts a new line?
<div>A box for a groupYes
<span>A box for some wordsNo, stays in the line

Part 2: Boxes with names

Some boxes have names that say what they are. Every big website uses them.

TagPart of the page
<header>The top: the name of the site
<nav>The menu (navigation)
<main>The main content. Only one
<section>One part of the content
<footer>The bottom: copyright, contact

Bu teglar sahifani bo'laklarga ajratadi: tepasi, menyu, asosiy qism, pasti.

Part 3: Why boxes with names?

  1. You can find things in your code faster
  2. Programs that read pages aloud know where the menu is
  3. Google understands your page better
  4. Next month, CSS will paint each box

Sneak peek: paint the header, the nav and the footer with colors.

How many <main> should a page have?

Watch out!

  • More than one <main> on a page
  • Putting the menu links outside <nav>
  • A <div> for every tiny thing. Use the named boxes when they fit
  • Forgetting a closing tag: </section>, </main>
