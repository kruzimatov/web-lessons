When I'm stuck
  1. Read my code slowly, line by line.
  2. Press Check my answer and look at the goals without a tick.
  3. Press Check my code and read what it says.
  4. Check that every tag that opens also closes.
  5. Look it up in My tags.
  6. Compare with the example in the lesson.
  7. Try Hint 1, then Hint 2.
  8. Still stuck? Ask your teacher.

Task 1 · Easy

3 checkboxes with labels: "I like cats", "I like dogs", "I like fish".

  • 3 checkboxes
  • Cats, dogs and fish
  • Every label's for is the same as its box's id
Hint 1

<input type="checkbox" id="cats"> then a label.

Hint 2

Do it 3 times with different ids.

Task 2 · Medium

"Cats or dogs?" with 2 radio buttons. Only one can be picked.

  • 2 radio buttons
  • Radio buttons share one name, so only one is picked
  • A label for each
Hint 1

Both radio buttons need the SAME name.

Hint 2

name="pet" on both.

Task 3 · Find the bug

There are 3 mistakes. Fix them.

  • Both radios have name="drink"
  • A real <select>, not an input
  • The option is in a select
  • The textarea closes
Hint 1

Radio names, a drop-down, a message box.

Hint 2

Both radios: name="drink". Use <select> and </select>. Close the textarea.

Task 4 · Medium

A drop-down "Favorite color" with 5 colors. Blue is chosen at the start.

  • A label "Favorite color"
  • 5 colors
  • Blue is selected
Hint 1

<select> with 5 <option>.

Hint 2

<option selected>Blue</option>.

Task 5 · Mini project

A "Pizza order" form: name, size (radio: small, medium, big), toppings (checkboxes: cheese, mushrooms, olives), drink (select), a message box, and an "Order" button.

  • A name box
  • 3 size radios
  • Radio buttons share one name, so only one is picked
  • 3 topping checkboxes
  • A drink drop-down
  • A message box
  • A Order button
Hint 1

Do it in parts: name, size, toppings, drink, message, button.

Hint 2

Radios share name="size". Checkboxes do not need a name.
