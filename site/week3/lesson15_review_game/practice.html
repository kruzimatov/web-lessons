When I'm stuck
  1. Read my code slowly, line by line.
  2. Press Check my answer and look at the goals without a tick.
  3. Press Check my code and read what it says.
  4. Check that every tag that opens also closes.
  5. Look it up in My tags.
  6. Compare with the example in the lesson.
  7. Try Hint 1, then Hint 2.
  8. Still stuck? Ask your teacher.

Task 1 · Easy

Test 1: a full page skeleton with the title "Test", an h1 and a p with one strong word.

  • Start with <!DOCTYPE html>
  • <html> opens and closes
  • A <body> that opens and closes
  • The title is Test
  • An h1
  • A p with one strong word
Hint 1

DOCTYPE, html, head, title, body.

Hint 2

<strong> goes inside the p.

Task 2 · Medium

Test 2: a numbers list of 3 planets. Each planet is a link to its Wikipedia page, opening in a new tab.

  • A numbers list of 3 planets
  • Each planet links to Wikipedia
  • Each opens in a new tab
Hint 1

<ol> with 3 <li>, each with an <a>.

Hint 2

target="_blank" in every link.

Task 3 · Find the bug

Test 3: there are 5 mistakes. Fix them all.

  • The header closes
  • The picture has alt
  • Water is H<sub>2</sub>O: sub
  • The table has border="1"
  • The footer opens and closes
Hint 1

5 mistakes: check every box, picture, number and table.

Hint 2

Close header. Add alt. sup should be sub. Add border. Footer needs an opening tag.

Task 4 · Medium

Test 4: a table with title cells Animal and Legs, and 3 animals.

  • Title cells: Animal and Legs
  • 3 animals
Hint 1

Title row with <th>.

Hint 2

Cat 4, Bird 2, Spider 8.

Task 5 · Mini project

Test 5: a form with a name box (required), a radio question with 2 answers, a select with 3 choices, and a button.

  • A form
  • A name box that is required
  • A radio question with 2 answers
  • Radio buttons share one name, so only one is picked
  • A drop-down with 3 choices
  • A button
Hint 1

text input, 2 radio, select, button.

Hint 2

Radios share a name. Name box is required.
